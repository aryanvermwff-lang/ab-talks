# 🚀 ABTalks — 60-Day Coding Challenge Platform

A mobile-first, high-trust coding challenge platform designed to transform ambitious students into production-ready engineers. Eliminate choice paralysis, build real daily proof of work, and showcase recruiter-ready progress.

---

## ✨ Features

- **📱 Mobile-First Responsive Design (390px baseline → Fluid Desktop)**: Crafted with high-grade SaaS aesthetics, neon accents, and fluid layouts.
- **🦉 Night Owl Mode**: Automatic late-night soothing theme with contextual encouragement and quick-submit shortcuts.
- **⚡ Multiple Tracks**:
  - 🌐 Full-Stack Web Development
  - 🧠 AI / ML Engineering
  - 💎 Data Engineering
  - ⚔️ Advanced DSA
- **🔥 Proof-of-Work Submissions**: Simulated GitHub commit & LinkedIn post verification with interactive status tracking.
- **💬 AI Rebel Mentor**: Integrated AI coding mentor with multi-provider support (Groq, Gemini, OpenAI, OpenRouter) and intelligent local fallback.
- **📊 Daily Heatmaps & XP Streak Tracking**: Real-time progress visualization and milestone badges.

---

## 🛠️ Tech Stack

- **Framework**: React 19 + Vite
- **Routing**: React Router v7
- **Styling**: Vanilla CSS with curated modern tokens and animations
- **Icons & Media**: SVG & Lucide-inspired components

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/aryanvermwff-lang/ab-talks.git
cd ab-talks
```

### 2. Install dependencies
```bash
npm install
```

### 3. Setup environment variables (Optional)
Copy `.env.example` to `.env` and add your preferred AI API key:
```bash
cp .env.example .env
```

### 4. Run Development Server
```bash
npm run dev
```

### 5. Build for Production
```bash
npm run build
```
